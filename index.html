☁️ Sincronización Multi-dispositivo

Conecta Supabase (gratis en supabase.com) para que varios celulares puedan validar boletos en tiempo real.

¿Cómo configurar Supabase? (pasos)
  1. Crea una cuenta gratuita en supabase.com
  2. Crea un nuevo proyecto
  3. Ve a Project Settings → API
  4. Copia la "Project URL" y la "anon public" key
  5. En el SQL Editor, ejecuta el script de la sección inferior
  6. Pega los valores aquí y presiona "Conectar"
-- Ejecutar en Supabase SQL Editor:
create table if not exists ep_events (
  id uuid primary key,
  name text not null,
  date text,
  time text,
  location text,
  description text,
  created_at bigint
);
create table if not exists ep_tickets (
  id uuid primary key,
  event_id uuid references ep_events(id),
  ticket_number text,
  attendee_name text,
  attendee_email text,
  is_used boolean default false,
  used_at bigint,
  created_at bigint
);
alter table ep_events  enable row level security;
alter table ep_tickets enable row level security;
create policy "public_all" on ep_events  for all using (true) with check (true);
create policy "public_all" on ep_tickets for all using (true) with check (true);
